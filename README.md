# Единая служба ИТ-поддержки

Школьный проект для Центра образования «Приоритет». На этапе подготовки доступна стартовая страница. Следующий этап — личные кабинеты.

## Запуск в VS Code

1. Установите Node.js 24 или новее с npm и откройте в VS Code вложенную папку «Единая служба ИТ-поддержки», содержащую `package.json`.
2. Во встроенном терминале выполните `npm start`. В PowerShell также можно использовать `npm.cmd start`. Все модули входят в Node.js.
3. Откройте http://127.0.0.1:3000 в браузере. Для остановки нажмите Ctrl+C.

Чтобы сменить порт, скопируйте `.env.example` в `.env` командой PowerShell `Copy-Item .env.example .env`, задайте, например, `PORT=3100` и перезапустите сервер. Используйте указанный порт в адресе страницы.

## Устройство проекта

`server.js` запускает локальный HTTP-сервер. Маршрут `/` возвращает `public/index.html`. После изменения страницы перезапустите сервер. Для хранения заявок выбрана PostgreSQL. На этом этапе подключение к базе не требуется.

Локальные параметры храните в `.env`. Git исключает этот файл. Каталоги «Техническое задание», «Шаблоны» и «Материалы для защиты» находятся на один уровень выше папки приложения. Журнал фактически выполненных работ ведётся в документе Word в «Материалах для защиты».
