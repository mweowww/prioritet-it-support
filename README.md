# Единая служба ИТ-поддержки

Локальный кабинет педагога для Центра образования «Приоритет». Можно зарегистрироваться по почте или телефону, войти, создать заявку, открыть её описание и увидеть текущий статус. При регистрации по телефону используйте код страны, например +7. В локальной версии принадлежность почты или номера сотруднику не проверяется.

## Первый запуск в Windows

1. Установите Node.js 24 или новее и PostgreSQL 18. Откройте папку с `package.json` в VS Code.
2. В терминале PowerShell выполните `npm.cmd ci`.
3. При работающем PostgreSQL на порту 5432 выполните `powershell.exe -NoProfile -ExecutionPolicy RemoteSigned -File .\scripts\setup-db.ps1`. Один раз введите пароль администратора `postgres` в локальном окне. Сценарий создаст базу `prioritet_support` и роль `prioritet_app` и запишет строку подключения в игнорируемый Git файл `.env`. Если у вас уже есть отдельная база, укажите её подключение в `DATABASE_URL` по образцу `.env.example`.
4. Выполните `npm.cmd start` и откройте http://127.0.0.1:3000. При запуске приложение создаёт таблицы. Для остановки нажмите Ctrl+C. При следующих запусках достаточно команды `npm.cmd start`.

Чтобы использовать другой порт приложения, задайте `PORT` в `.env`. Сервер доступен с этого компьютера. Заявки сохраняются в PostgreSQL после перезапуска. Справочники и обработка исполнителем запланированы отдельно.

ТЗ, шаблоны и материалы защиты находятся на один уровень выше каталога приложения. Журнал работ хранится в документе Word в «Материалах для защиты».
